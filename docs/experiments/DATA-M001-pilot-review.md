## Cross-style findings and decision

The ten looks are often visually separable by color and intensity, so the taxonomy is **not disproved** by this pilot. However, style control is not sufficiently localized or plausible. `Natural` and `Dewy Peach` reconstruct the first identity outright; `Matte Nude` removes skin texture on both; `Smoky`, `Rosy`, `Bronze`, and `Bold` often produce mask-like eye or cheek areas. `Classic Red Lip` is a useful proof that the model responds to a specific color instruction, but even that result changes lip geometry. The `No-Makeup` outputs preserve more of the source largely because they barely edit it, which makes them weak supervision for a distinct class. This directly contradicts the hoped-for implication that technically successful Base generation would yield training-ready directional pairs.

Both identities retain broadly recognizable hair and scene composition across many outputs, and `003025` retains the coat. Nevertheless, color/lighting shifts occur, especially in Natural, Dewy and Matte; `054109` has little clothing visible, limiting that check. The dominant failure is **face and skin reconstruction**, not missing style response or wholesale background replacement. Two identities cannot establish a failure rate for the full dataset, but repeated failure across these twenty outputs is enough to block automatic expansion.

Recommendation: do **not** mark the pilot ACCEPT, run the remaining 100, or train MAKEUP-001 from these images. Preserve this archive as the technical and visual baseline. The next step should be a bounded preservation-method investigation before further dataset generation, with two existing sources and a small subset of styles (for example Natural, Classic Red Lip, and Smoky). A prompt-only revision might correct excessive color for some styles but is unlikely by itself to fix the cross-style geometry reconstruction already present despite explicit preservation instructions. This is a proposed next step, not authorization to add masking, face parsing, or change the approved architecture. The Supervisor should review these sheets and choose the corrective experiment before another GPU run.
